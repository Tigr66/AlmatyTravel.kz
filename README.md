
# Project

## Установка

1. Клонируйте репозиторий:

```bash
git clone <repository-url>
```

2. Перейдите в папку проекта:

```bash
cd <project-folder>
```

3. Установите зависимости:

```bash
npm install
```

## Запуск

Запустите проект в режиме разработки:

```bash
npm run dev
```

После запуска проект будет доступен по локальному адресу, указанному в терминале.
